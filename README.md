## Задача 1. Преобразование текстового файла

**Условие (вариант 5).** В созданном текстовом файле оставить в каждой строке не более
двух слов. Слова, выходящие за этот предел, поместить в отдельный файл.
В первом файле-результате в тех строках, которые содержат менее двух слов, в конец строки
должен быть добавлен символ `=`. Во втором файле-результате пустых строк оставаться не должно,
а перед непустыми строками должны быть указаны их номера в исходном файле, отделённые от
остального текста одним пробелом. Исходный файл остаётся без изменения.

**Файлы:** [`task1/task1.sh`](task1/task1.sh), исходный пример — [`task1/input.txt`](task1/input.txt).

**Запуск:**
```bash
cd task1
./task1.sh            # или: ./task1.sh мой_файл.txt
```

**Идея решения.**
- Первый результат (`result1.txt`): `sed` усекает строку до первых двух слов
  (шаблон срабатывает только при наличии 3-го слова), затем второй `sed` дописывает `=`
  к строкам, в которых нет пробела (значит, слов меньше двух).
- Второй результат (`result2.txt`): `nl -ba` нумерует строки, `sed -n '.../p'` печатает
  «номер + остаток строки» только для строк, где остаток есть (≥3 слов). За счёт этого
  пустых строк не возникает.

**Протокол (на примере `input.txt`):**

Исходный файл:
```
1  one two three four five
2  alpha
3  sun moon stars
4  hello world
5  singleword
6  a b c d
```
`result1.txt`:
```
one two
alpha=
sun moon
hello world
singleword=
a b
```
`result2.txt`:
```
1 three four five
3 stars
6 c d
```

## Задача 2. Выборка из «базы данных» query[1-5]

**Условие (вариант 5).** Из информации, содержащейся в файлах `query[1-5]`, определить
**товар, которого было заказано наибольшее количество экземпляров в одном заказе**.

**Файлы:** [`task2/task2.sh`](task2/task2.sh); исходные данные курса — `task2/data/` (`query1`…`query5`).

**Запуск:**
```bash
cd task2
./task2.sh data                               # на приложенных файлах курса
./task2.sh /путь/к/каталогу/с/query-файлами   # по умолчанию — текущий каталог
```

**Реальная структура файлов** (база «JOCKSPORTS»):
- `query5` — позиции заказов, поля через пробел:
  `<поз> <N_заказа> <код_товара> <цена> <КОЛИЧЕСТВО> <сумма>` (количество — 5-е поле);
- `query3` — каталог товаров, поля через `!`:
  `<код_товара>!<название>!<цена1>!<цена2>!<дата>`.

**Решение (один конвейер, коды товаров не вписываются вручную).**
```bash
# 1) максимальное количество экземпляров (5-е поле query5)
tr -s ' ' < query5 | cut -d' ' -f5 | sort -nr | head -1

# 2) названия товаров, заказанных в этом количестве (коды берутся из данных автоматически)
max=$(tr -s ' ' < query5 | cut -d' ' -f5 | sort -nr | head -1)
tr -s ' ' < query5 | cut -d' ' -f3,5 | grep " $max\$" | cut -d' ' -f1 \
  | sed 's/^/^/; s/$/!/' | grep -f - query3 | cut -d'!' -f2 | sed 's/ *$//'
```

**Идея решения.**
1. `cut -d' ' -f5 | sort -nr | head -1` — выделить столбец количества (5-е поле) и найти максимум.
2. `cut -d' ' -f3,5 | grep " $max\$" | cut -d' ' -f1` — выбрать коды товаров, у которых количество равно максимуму (коды берутся из данных, не вписываются руками).
3. `sed 's/^/^/; s/$/!/' | grep -f - query3` — превратить коды в шаблоны `^код!` и найти записи товаров в `query3`.
4. `cut -d'!' -f2 | sed 's/ *$//'` — вывести только названия товаров (без кодов, цен и дат).

**Ответ (на приложенных данных):** наибольшее количество экземпляров в одном заказе —
**1000 шт.**, и это ничья из трёх товаров:
- **ACE TENNIS BALLS-3 PACK** (код 100870) — заказ № 614;
- **ACE TENNIS BALLS-6 PACK** (код 100871) — заказ № 614;
- **SB ENERGY BAR-6 PACK** (код 200376) — заказ № 620.

## Задача 3. Подсчёт файлов в каталоге

**Условие (вариант 5).** Определить количество (не подкаталогов и не ссылок) файлов
в каталоге `/student`.

**Файлы:** [`task3/task3.sh`](task3/task3.sh).

**Запуск:**
```bash
cd task3
./task3.sh                 # считает в /student
./task3.sh /другой/каталог # можно указать любой каталог
```

**Решение (одной командой):**
```bash
find /student -maxdepth 1 -type f ! -type l | wc -l
```
`-type f` отбирает только обычные файлы — каталоги (`d`) и символические ссылки (`l`)
в выборку не попадают; `-maxdepth 1` ограничивает поиск самим каталогом `/student`;
`wc -l` считает их количество.
